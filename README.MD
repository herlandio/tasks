# Sistemas de Tasks

Este projeto é um sistema de gerenciamento de tasks. O sistema foi desenvolvido em PHP 8.2 com um banco de dados MySQL 5.7, Docker, Docker-compose e segue boas práticas de programação.

### Clone o repositório:
```
git clone https://github.com/herlandio/tasks.git
```
### Como usar via Docker

### Pré-requisitos

- Docker instalado.

1. Suba os containers:
    ```
    docker-compose up -d
    ```
2. Acesse a aplicação:
    - Abra o navegador e acesse http://localhost:9000
